## 2. 数据分级（L0 / L1 / L2）

定义与判定在 `backend/edge_cloud.py`（`PrivacyLevel` + `PrivacyGuard.classify`）。

| 级别 | 内容 | 处置 | 代码位置 |
|---|---|---|---|
| **L0 高敏** | 音视频流、人脸/画面、健康与作息、跌倒/看护、老人小孩相关、**原始 CSI / 房间存在时间线** | **强制端侧处理，绝不上云**；`allow_cloud=False` 时连慢环都不进 | `edge_cloud.L0_KEYWORDS`、`L0_SENSOR_KEYS` |
| **L1 中敏** | 温度/湿度/光照/空气质量/能耗/设备状态 | 可上云，但**只发脱敏摘要**（数值、设备类别；不含设备 ID/家庭名） | `PrivacyGuard.sanitize` |
| **L2 低敏** | 意图语义、指令文本 | 可上云做复杂规划 | 默认 |

`agent.decide()` 的第一步就是分级：`route = self.router.route(text, sensors)`，
`route.cloud_allowed=False` 时 `root.plan(..., allow_cloud=False)`，**规则层照常工作**，
只是不进慢环。每次真正上云都会调 `guard.record_upload(...)` 留痕，可用
`GET /api/edge-cloud/audit` 复核。

### 2.1 CSI 与房间数据（v2.0）

- **原始 CSI 永不落库、永不上云**：固件在 ESP32 上算出 `motion/idle/score`，
  后端只接收派生事件；`wifi_csi.json` 明确 `raw_csi_policy: "never_store"`。
- 房间四态只保存在内存（`RoomService.states`），状态变化时间线最多 500 条；
  `/api/rooms` 返回的是**派生状态 + 证据来源名**，不含任何波形/相位数据。
- 六路旁证中 PIR/插座/门磁/作息当前为仿真量，证据里逐项标
  `source_kind="simulated"`；接真实器件后不改变数据分类。
- 上云（慢环）只会看到"客厅有人/无人/不确定"这类**结构化标签**，
  不会看到 CSI、画面、音频。

## 3. 出网点清单（穷举）

| # | 目的地 | 发出什么 | 触发条件 | 能否关闭 |
|---|---|---|---|---|
| ① | 用户配置的 LLM 端点（智谱/DeepSeek/通义/Moonshot/本地 Ollama） | 脱敏后的指令文本、传感器摘要、设备能力清单（prompt）、经验案例摘要 | 仅当规则层未命中且 `allow_cloud=True`；或 22:00 日报走 LLM；或手动触发日报 | `LLM_OFFLINE=1` 或清空 `LLM_API_KEY`（全链路仍可演示） |
| ② | `edge-tts`（微软在线语音合成） | **回复文本**（转语音用） | 仅当调用 `POST /api/tts`（前端点"朗读"） | 不调用该接口即零出网；前端可关朗读 |
| ③ | PyPI / 镜像源 | 依赖包下载 | 构建镜像或 `pip install` 时 | 离线安装：预置 wheel 或使用带依赖的镜像 |

**没有的东西**（同样重要，避免被问住）：

- 没有遥测/埋点/崩溃上报；
- 没有云同步、没有账号体系、没有第三方统计 SDK；
- **不上传原始 CSI、房间状态、旁证读数**（只在本机内存）；
- 前端不加载 CDN 资源（Three.js、GLB 模型、CSS 全部本地）；
- 规则层、感知层、告警层、记忆层、审计**都不出网**。

## 4. 各类数据落在哪、留多久

| 数据 | 位置 | 保留策略 | 是否可删 |
|---|---|---|---|
| 设备状态 / 传感器读数 | 内存（`DeviceRegistry` / `SensorSimulator`） | 进程存活期；重启回到初始值 | 重启即清 |
| 审计日志（谁在什么版本执行了什么） | 内存环形缓冲 `StateStore.audit_log` | 最多 2000 条（`max_log`），超出丢弃 | 重启即清；**注意"今日动作数"是下界** |
| 习惯统计 | `data/user_habits.json` | 长期，延迟落盘（最多丢 2 秒） | 删文件 |
| 经验库 | `data/experience.jsonl` | 长期，append-only（含用户评分） | 删文件 |
| 家庭日报 | `data/reports/` | 长期 | 删文件 |
| 自定义事件路由 | `data/event_routes_custom.json` | 长期（用户确认后才写入） | `DELETE /api/event-routes/{id}` |
| 规则草稿 | **仅内存** `DraftStore` | 10 分钟 TTL，重启即丢 | 自动过期 / 手动取消 |
| 房间四态 / 时间线 | **仅内存** `RoomService` | 时间线最多 500 条；重启即清 | 重启即清 |
| 撤销记录（前态快照） | **仅内存** `UndoStore` | 最近 300 条；10 分钟窗口后可撤销失效 | 重启即清；窗口过期自动失效 |
| 自治状态 | `data/adaptation_state.json` | 长期（等级/模式/反馈计数/漂移） | 删文件即回冷启动 |
| 待确认高危动作 | 内存 `StateStore.pending` | 租约 TTL（10 秒） | 自动过期 |
| 密钥 | `.env`（不进 git） | 长期 | 轮换见《凭据轮换清单》 |
| 运行日志 | `logs/`（若启用） | 由部署方管理 | 删文件 |

## 5. 加密与传输

- 默认 HTTP（家庭内网/回环）。**跨设备访问请用 Tailscale 之类的点对点网络，
  不要做公网端口转发**；如需 HTTPS，在最前面加一层反向代理。
- 出网到 LLM 的链路是 HTTPS（由 `base_url` 决定）。
- 本地文件不加密。`data/` 里可能含家庭作息，分享/交付前请脱敏（见 §7）。

## 6. 如何当场证明"断网也能跑"

```powershell
$env:LLM_OFFLINE="1"
python -m uvicorn backend.main:app --port 8000
```

此时：

- `/api/config` 的 `llm_configured` 仍可能是 true（Key 在），但**不会发起请求**；
- 规则层、感知层、告警、日报模板降级、草稿生成全部可用；
- `GET /api/metrics/llm` 的慢环降级率会上升，且 `decision_trace` 里出现 `degrade` 步
  —— 降级是**可见**的，不是静默消失。

回归门禁 `python run_tests.py` 默认就带 `LLM_OFFLINE=1`，所以 CI 里也不会出网。

## 7. 交付/演示前的脱敏检查

1. `data/` 是否要一起给？给之前删掉 `user_habits.json`、`experience.jsonl`、`reports/`。
2. 截图/录屏是否带出真实姓名、地址、门锁状态、摄像头画面？
3. `.env` 不在压缩包里；`git status` 干净。
4. 演示用设备名建议保持虚拟设备（"客厅吊灯"），不要改成真实家庭布局。

## 8. 与答辩话术的对应

| 可能被问 | 回答落点 |
|---|---|
| 你们的音视频会不会上云？ | L0 强制端侧（`edge_cloud.L0_KEYWORDS` + `allow_cloud=False`），原始画面只做本地结构化标签 |
| 凭什么信你？ | `GET /api/edge-cloud/audit` 是每次上云的留痕；`LLM_OFFLINE=1` 可当场断网演示 |
| 大模型看到了什么？ | 脱敏后的指令 + 传感器摘要 + 设备能力清单；不含画面、音频、住址 |
| 日报会不会把家里数据发出去？ | 日报走同一套分级；断网时模板降级，仍能出文案（`jobs/daily_summary.py`） |
| 语音合成算不算出网？ | 算。`/api/tts` 会把**回复文本**发给 edge-tts；不点朗读即零出网，本文如实列出 |
